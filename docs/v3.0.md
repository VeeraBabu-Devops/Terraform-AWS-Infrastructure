# Terraform AWS Infrastructure - v3.0

## Overview

Version 3.0 enhances the Terraform project by replacing hardcoded values with **Terraform Variables**, making the infrastructure reusable, flexible, and easier to maintain.

Instead of modifying the Terraform code for every deployment, configuration values such as the AWS region, AMI ID, instance type, CIDR blocks, Availability Zone, and tags are now supplied through variables.

This follows Infrastructure as Code (IaC) best practices and improves the portability of the project across different AWS environments.

---

## What's New in v3.0

- Introduced Terraform Variables
- Removed hardcoded configuration values
- Added `variables.tf` for variable declarations
- Added `terraform.tfvars` for variable values
- Added `outputs.tf` to display resource information
- Added `versions.tf` for Terraform and provider configuration
- Improved project structure
- Increased code reusability and maintainability
