# Terraform AWS Infrastructure - v2.0

## Overview

This project demonstrates how to provision a complete AWS networking environment using **Terraform (Infrastructure as Code)**.

Unlike the initial version, which launched an EC2 instance in the default VPC, this version builds the networking infrastructure from scratch by creating a custom VPC and all the required networking resources before deploying the EC2 instance.

This project is part of my Terraform learning journey and follows Infrastructure as Code (IaC) best practices.

# Terraform Workflow

Initialize Terraform

```bash
terraform init
```

Validate Configuration

```bash
terraform validate
```

Format Terraform Code

```bash
terraform fmt
```

Preview Infrastructure Changes

```bash
terraform plan
```

Create Infrastructure

```bash
terraform apply
```

Destroy Infrastructure

```bash
terraform destroy
```
